## 2. What the AI Got Wrong & How Human Judgment Corrected It

1. **CRM Payload Attribute Access Path:**
   - *AI Generation:* `resp.crm_payload.dispatch_authorized`
   - *Human Correction:* Schema investigation confirmed the field is located at `resp.crm_payload.metadata.dispatch_authorized`. Fixed in evaluation scripts and regression tests.
2. **Missing Exception Handling on Malformed Input (TC-12):**
   - *AI Generation:* Regression runner did not wrap `LeadInput(**inp)` in `try/except ValidationError`, causing TC-12 to throw an unhandled script crash.
   - *Human Correction:* Added Pydantic `ValidationError` exception handling to verify HTTP 422 behavior without crashing test suites.
3. **Silent Missing Fallback Telemetry:**
   - *AI Generation:* Assumed defining `EventType.FALLBACK_ACTIVATED` in `audit_logger.py` was sufficient.
   - *Human Correction:* Discovered during test execution that `pipeline.py` never called `_audit(..., EventType.FALLBACK_ACTIVATED)`. Added targeted emission in `pipeline.py`.
4. **Pre-Approval State Inspection in Evaluation Script:**
   - *AI Generation:* Script approved the lead *before* capturing pre-approval variables, resulting in the misleading output `Pre-Approval Status: APPROVED`.
   - *Human Correction:* Restructured `run_proxy_sdr_evaluation.py` to capture pre-approval state snapshots immediately upon pipeline completion and before executing `handle_approval_action()`.
